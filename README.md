# ORD_JHelper 🌸

워크래프트 III ORDR 플레이를 위한 비공식 Windows x64 보조 프로그램입니다. 이 저장소는 **배포 파일과 업데이트 안내용**입니다.

**[최신 버전 다운로드](https://github.com/passedjina-star/ORD_JHelper/releases/latest)**

## 설치와 실행

1. Releases에서 `ORD_JHelper-Windows-x64.zip`을 받습니다.
2. ZIP 전체를 압축 해제하고 `ORD_JHelper.exe`를 실행합니다. `Data`·`Simulation` 폴더를 함께 두세요.
3. 게임 없이 확인하려면 `Simulate.cmd`를 실행합니다.

기본 선택 맵은 ORDR 2.323이며 2.321·2.322 선택도 유지합니다. 게임 메모리는 읽기 전용 참고로 사용합니다. 실제 소유·전체 패의 정확성·전투 효과·클리어 성능을 보증하지 않습니다.

## 주요 기능

- 보유 패 참고 인식과 성장 유닛 유지, 수동 재동기화
- 목표 후보·능력 필터·등급 배지·부족 재료 안내
- 보유 상위의 물리/마법 방향과 공동 재료를 고려한 자동 팀 구성
- 조합으로 줄어드는 지원 능력 비교와 다음 제작 안내
- 패 수치·동봉 클리어 자료 비교·미션/보물·정보판·HUD
- 약 1분 간격 로컬 플레이 기록, 더미 테스트

## 앱 안에서 업데이트

**0.3.19부터** `더보기 → 설정 → 업데이트`에서 `지금 확인 → 다운로드 → 설치 후 재시작`을 사용합니다. 시작 시 자동 확인은 선택 사항이며 기본값은 꺼짐입니다. 플레이 도중 강제 설치하지 않습니다.

0.3.18 이하 사용자는 먼저 0.3.19 이상의 ZIP을 한 번 직접 받아야 합니다. 설치는 도우미만 종료·재실행하며 게임을 종료하지 않습니다. 설정과 개인 기록은 `%LOCALAPPDATA%/ORD_JHelper`에 보존합니다. 파일 교체 또는 설치 검사에 실패하면 이전 파일로 복구합니다.

업데이트 안내의 ECDSA 서명과 ZIP의 SHA-256을 검증합니다. 이는 **Windows 코드 서명(Authenticode)이나 백신 인증과 별개**이며 현재 EXE는 Windows 코드 서명이 없습니다. ZIP에는 파일 해시와 배포 검사 정보가 포함됩니다.

## VirusTotal 리포트

앞으로 새 버전을 배포할 때 최종 EXE와 ZIP을 각각 VirusTotal로 검사하고, 릴리스에 `VIRUSTOTAL-REPORT.md`와 `VIRUSTOTAL-REPORT.json`을 첨부합니다. 파일 해시·검사 시각·엔진별 판정·원본 결과 링크를 확인할 수 있습니다. 미완료 검사나 탐지 결과를 무해로 표시하지 않습니다.

**0.3.19는 이 절차 도입 전에 공개되었으며, 아직 VirusTotal 리포트를 첨부하지 않았습니다.** 실제 검사가 완료된 뒤 추가합니다. 배포자의 검사 대상은 공개 배포 파일뿐이며 앱이 이용자의 파일·로그를 VirusTotal에 보내지는 않습니다.

프로그램 소스는 릴리스에 포함하지 않습니다. GitHub가 자동 제공하는 `Source code` ZIP/tar.gz는 이 안내 저장소의 파일을 묶은 것으로, 프로그램 소스 묶음이 아닙니다.

## 외부 통신과 기록

외부 연결은 이 저장소의 업데이트 확인·파일 다운로드에만 사용합니다. GitHub와 GitHub 배포 파일 서버에 접속하며 일반 웹 요청의 IP·User-Agent 등은 해당 서비스에 전달됩니다. 앱은 개인 패·플레이 로그·원격 프로필을 업로드하지 않습니다. 클리어/패치노트 동기화도 제공하지 않습니다. 동봉 자료의 비교 기능은 로컬에서 동작합니다.

개인 로그·분석 자료·게시자 비밀키·GitHub 인증정보는 이 저장소나 배포 ZIP에 포함하지 않습니다. 원본 데이터의 출처와 무결성 정보는 별도로 유지하며 이 저장소가 원자료의 새로운 재배포 라이선스를 부여하지 않습니다.

오류를 제보할 때 버전과 증상을 적어 주세요. 개인 플레이 로그는 공개 이슈에 올리기 전에 내용을 확인하세요.
